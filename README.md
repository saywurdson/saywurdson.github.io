# saywurdson.github.io

Personal portfolio site for Kwasi Agyeman, PharmD — healthcare data engineer specializing in OMOP CDM, clinical terminology standards, and data pipeline development.

**Live site:** [saywurdson.github.io](https://saywurdson.github.io)

## Featured Projects

- [TX Workers' Comp Analytics](https://github.com/saywurdson/txwc) — End-to-end pipeline transforming Texas workers' comp billing data into OMOP CDM using dlt, dbt, and DuckDB
- [Claims DB](https://github.com/saywurdson/claims_db) — Curated collection of open source healthcare claims datasets in a single DuckDB file
- [MIMIC-IV → OMOP CDM](https://github.com/saywurdson/mimic-iv-dbt) — DuckDB + dbt pipeline mapping the MIMIC-IV critical-care dataset to OMOP CDM v5.4, with clinical KPI marts and a Streamlit dashboard
- [MIMIC-III → OMOP CDM](https://github.com/saywurdson/mimic-iii-dbt) — Sibling pipeline mapping MIMIC-III v1.4 onto the same OMOP CDM v5.4 output layer, with concept-mapping seeds and clinical KPI marts
